# shopone

A single-page ecommerce storefront demo: product grid with search, category filters and sorting, a slide-out cart, and a demo checkout. No backend — products are static data and no payment is processed.

## Stack

React 19 + TypeScript + Vite + Tailwind CSS.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run lint
```
